# SWYNEX Final AI Application

## Project Title
AI-Based Suspicious LinkedIn Profile Detection

## 1. Problem Statement
Fake and suspicious professional profiles can create
trust and security issues on professional networking
platforms.

This project aims to build an educational AI prototype
that identifies suspicious profile patterns.

## 2. Technologies Used
- Python
- Pandas
- Scikit-learn
- Decision Tree Classifier
- Streamlit

## 3. Methodology
The application uses profile features such as:
- Account age
- Number of connections
- Profile completeness
- Number of skills
- Work experience
- About section length

A Decision Tree model is trained using synthetic
sample data to classify profiles.

## 4. Application Demo
Users enter profile details and receive a prediction
of Genuine-looking or Suspicious-looking.

Screenshots are included in the screenshots folder.

## 5. Limitations
- The project uses synthetic training data.
- Predictions are not guaranteed to be accurate.
- It does not access private LinkedIn information.
- It cannot confirm whether a real person is genuine.

## 6. Ethical Considerations
- No private user information is collected.
- Synthetic data is used for demonstration.
- Predictions should not be treated as proof of fraud.
- Human verification is necessary.

## 7. How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
